# squeezy

A small, self-contained **SqueezeMetrics dashboard** — a single static HTML page
(`index.html`) that displays SqueezeMetrics-style data (DIX / GEX+ and related
series) in the browser. No build step and no server: open `index.html` directly.

## Contents

| File | What it is |
|---|---|
| `index.html` | The dashboard page (self-contained HTML/JS/CSS). |
| `SqueezeMetrics Dashboard.url` | A Windows shortcut to a local working copy on the author's machine — machine-specific, not needed to use the page. |

## Related

- Daily SqueezeMetrics "Yacht Club" PDF reports are downloaded by a separate
  local skill (`squeezy-download`), not this repo.
